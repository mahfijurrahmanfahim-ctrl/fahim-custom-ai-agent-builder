# FAHIM AUTOPILOT AI\n\nApproval-first prospect pipeline for Fahim Graphic Design. This initial UI prototype lets you record real business prospects, prepare personalised outreach drafts, review them, and copy them manually.\n\n## Current limitations\n- Prospects are stored in this browser's localStorage only.\n- No automated web research, overnight scheduler, shared database, email connection, or message sending is enabled yet.\n- 'Approved' means approved by you for manual use; it does not send anything.\n\n## Next implementation phase\nAdd durable Supabase storage, a verified public-business research connector, a scheduled research worker, deduplication and suppression lists, and a server-side approval gate. Configure credentials as Vercel encrypted environment variables; never commit API keys.\n\n## Safeguards\nNever fabricate prospects or contact details. Store source URLs and verification dates. Use public business contact channels only, respect opt-outs and applicable Portugal/EU privacy and marketing rules, and require human approval before any outreach is sent.\n
