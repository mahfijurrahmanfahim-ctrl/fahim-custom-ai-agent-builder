# FAHIM Free API Lab

An independent Streamlit app for cataloguing free AI inference providers and testing real API calls. It is isolated on the free-api-lab branch and does not modify the main FAHIM AI app.

## Features
- Loads the machine-readable provider directory from https://freeinference.dev/data/providers.json
- Shows provider access methods, free-tier notes, model names, verification dates and endpoints
- Runs real chat-completion tests for selected providers
- Separates anonymous endpoints from services that require your own API key
- Records HTTP status, latency, model ID and a short response in the current session
- Exports provider and test data to CSV

## Keyless tests
- LLM7 anonymous endpoint
- OVHcloud AI Endpoints anonymous endpoint

These are shared public services. Rate limits and availability can change.

## Providers with credential adapters
Gemini, Groq, OpenRouter, Mistral, NVIDIA NIM, Cohere, Cloudflare Workers AI, Z.AI, Aion Labs, Gonka Broker, ModelScope and SiliconFlow.

Only enter keys generated by your own accounts. Do not commit keys to GitHub. The app keeps entered credentials in the active Streamlit session and sends them to the selected provider for the request. Use a trusted/private deployment when entering credentials.

## Run locally

    cd api-lab
    python -m venv .venv
    pip install -r requirements.txt
    streamlit run app.py

## Deploy separately on Streamlit Community Cloud
1. Choose this GitHub repository.
2. Select branch: free-api-lab.
3. Set Main file path to api-lab/app.py.
4. Deploy.

The existing root app.py is unchanged.

## Limitations
The upstream directory includes different kinds of services, not all direct chat-completion APIs. The live tester supports only the adapters shown in its selector. Other catalogue entries are directory-only until a correct adapter is added. A PASS proves only that the test request worked at that moment.
