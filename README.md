# 🤖 FAHIM CUSTOM AI AGENT BUILDER PRO

### Build Your Own Personal AI Assistant

Create your own AI assistant using your personal profile, business information, skills, and custom instructions.

## 🚀 Features

- Create personalized AI assistants.
- Paste your own personal or business profile.
- Customize assistant name and role.
- Choose response language.
- Select communication style.
- Add custom AI instructions.
- Chat with your AI assistant.
- View conversation history.
- Download conversations as text files.
- Free open-source AI model.
- No paid AI API key required.

## 🧠 AI Model

Powered by:

`google/flan-t5-small`

Model provided by Hugging Face Transformers.

## 🛠️ Technologies

- Python 3.11
- Streamlit
- Hugging Face Transformers
- PyTorch
- SentencePiece

## ⚙️ Installation

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## ☁️ Deployment

Deploy using Streamlit Community Cloud:

https://share.streamlit.io/

Select your GitHub repository and set:

Main file path: `app.py`

- Conversation history is session-based.
- Free hosting has resource limitations.
